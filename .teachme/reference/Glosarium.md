# Glosarium

| Istilah | Makna di materi ini |
|---|---|
| Agent | Loop model yang dapat memanggil tool untuk menyelesaikan tugas |
| Tool | Fungsi terstruktur yang tersedia bagi model |
| Thread | Percakapan dan ruang urutan event |
| Run | Pekerjaan menjawab satu input, dengan lifecycle tersimpan |
| Delta | Potongan teks publik sementara |
| Ledger | Catatan event aplikasi yang disimpan untuk dibaca ulang |
| Snapshot | Representasi state UI pada `through_seq` tertentu |
| SSE | Pengiriman event HTTP satu arah dari server ke browser |
| Cursor | Batas sequence yang sudah diamati |
| Checkpoint | State graph yang disimpan untuk kelanjutan eksekusi |
| Lease | Hak menjalankan pekerjaan yang berbatas waktu |
| Fencing | Penolakan penulisan oleh eksekutor yang kehilangan hak |
| RAG | Mengambil konteks dokumen untuk membantu jawaban model |
