# Mission: AI agent dan streaming Kimmy

## Why
Mempelajari penerapan AI agent dan streaming pada proyek Kimmy melalui kode yang benar-benar digunakan. Sasaran kerja sementara: mampu menelusuri sebuah pertanyaan dari UI sampai jawaban tersimpan, serta menjelaskan apa yang terjadi saat koneksi terputus.

## Success looks like
- Menjelaskan loop model → tool → model beserta batas tanggung jawab service.
- Menelusuri potongan teks dari LangGraph ke database, SSE, dan cache UI.
- Membedakan replay event, resume checkpoint, dan retry run.
- Menunjuk fungsi yang relevan saat UI berhenti memperbarui jawaban.

## Constraints
- Bahasa Indonesia; pelajaran 5–10 menit, berbasis kode lokal.
- Tingkat awal belum diketahui; mulai dari alur konkret lalu masuk recovery.
- Vault berada di `.teachme` sesuai permintaan pengguna.

## Out of scope
Belum ada pengecualian topik eksplisit dari pengguna. Implementasi fitur produk bukan bagian permintaan belajar ini.
